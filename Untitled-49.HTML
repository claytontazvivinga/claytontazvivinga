About Mazowe Hydrology Project

This application provides advanced tools for visualizing and analyzing hydrological data in the Mazowe catchment area of Zimbabwe.

Features include:

  • Interactive map with multiple base layers
  • Hydrological data visualization
  • KML file upload and analysis
  • Measurement tools for distances and areas
